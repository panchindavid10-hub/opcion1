# Muso Business — Opción 1

Propuesta de sitio web para **Muso Business**, empresa ecuatoriana de venta y mantenimiento de repuestos
aeronáuticos y de equipos de apoyo en tierra (GSE).

**Vista previa:** https://panchindavid10-hub.github.io/opcion1/

- HTML, CSS y JavaScript puro, sin dependencias.
- Bilingüe: español (raíz) e inglés (`/en/`).
- Catálogo con buscador por número de parte, lista de cotización por WhatsApp o correo y
  animación del avión que se arma con el scroll.
- SEO: títulos y descripciones por página, `hreflang`, datos estructurados (Schema.org), `sitemap.xml`.

Detalles de estructura, edición de productos y pasos para publicar en el dominio final: ver [LEEME.md](LEEME.md).

> Los productos del catálogo son de ejemplo y el correo es provisional hasta definir el dominio.
